## Assignment Programs

1. **Positive, Negative or Zero** – Checks whether a given number is positive, negative, or zero using if-else statements.

2. **Area and Perimeter of Rectangle** – Calculates the area and perimeter of a rectangle using its length and breadth.

3. **Voting Eligibility** – Checks whether a person is eligible to vote based on their age.

4. **Customer Payable Amount** – Calculates the final payable amount based on order value, membership type, discount, and delivery charges.

5. **Loan Approval System** – Determines loan eligibility based on age, monthly income, and credit score.

6. **Login Validation** – Validates the user's ID and password to determine whether the login is successful.

7. **Student Grade Calculator** – Assigns a grade based on the student's marks and checks whether the marks are valid.

8. **BMI Calculator** – Calculates Body Mass Index using weight and height and classifies the result into a category.

9. **Vowel Checker** – Checks whether a given character is a vowel.
